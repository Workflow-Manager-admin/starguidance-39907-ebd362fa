# StarGuidance React Frontend

This is the React frontend for StarGuidance—a web app providing daily horoscopes and personalized AI astrology guidance.

## Features

- **User Input Form**: Collects user birth name, date, place, and optional guidance question.
- **Results Panel**: Shows zodiac sign, date range, daily horoscope, AI guidance.
- **Themed Zodiac Illustrations**: Rendered as pastel-styled inline SVG art for each sign.
- **Pastel & Minimal UI**: Clean, bright, and accessible (dominant colors:  
  - primary: `#D8BFD8`
  - secondary: `#E6E6FA`
  - accent: `#9370DB`
  - white background, subtle gray: `#F7F6FB`
- **API Integration**: POSTs to `/api/horoscope` on backend for results.

## More

- Zodiac keywords used: Aries, Taurus, Gemini, Cancer, Leo, Virgo, Libra, Scorpio, Sagittarius, Capricorn, Aquarius, Pisces.
- Edit `src/App.js` or `src/App.css` to update styles or UI.

**Start the development server:**  
```bash
npm start
```

**Build for production:**  
```bash
npm run build
```
